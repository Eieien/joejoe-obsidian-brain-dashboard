# Pixel playground

A dithered image — hover it to dissolve the dither and see the original:

```dither
src: Attachments/pixel-fish.png
palette: gameboy
pixel: 3
height: 260
```

An animated pixel field — move the mouse to light it, click for ripples:

```dither
palette: amber
pixel: 4
height: 180
```

Options: `src` (an image in your vault or a link; leave it out for a pixel field), `palette` (theme, gameboy, amber, ice, rose), `pixel` (size of each pixel), `height`, and `reveal: false` to turn off the hover effect.
